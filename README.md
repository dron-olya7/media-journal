# MediaJournal - Дневник медиа-потребления
## Описание проекта
MediaJournal — это веб-приложение для учета потребляемого медиаконтента (фильмы, сериалы, книги). Пользователи могут вести персональную базу просмотренных/прочитанных произведений, оценивать их, добавлять рецензии.

## Ключевые функции
### Авторизация и безопасность
- Регистрация и вход с JWT-токенами

- Хеширование паролей (bcrypt)

- Защита роутов middleware авторизации

- Ролевая модель (пользователь/админ)

 ### Учет медиаконтента
- Типы контента: фильмы, сериалы, книги

- Поля для записей:

    - Название, год выпуска

    - Рейтинг (0-10)

    - Статус (запланировано, в процессе, завершено)

    - Жанры (множественный выбор)

    - Постер/обложка

    - Рецензия/отзыв

    - Даты добавления и изменения

### Аналитика и статистика
- Общее количество записей

- Распределение по типам контента

- Средний рейтинг

- Самые популярные жанры

- Прогресс потребления

### Персональный кабинет
- История добавленных записей

- Избранные произведения

- Настройки профиля

- Экспорт данных

### Технологический стек
#### Backend 
- Node.js + Express - серверная часть

- SQLite3 - база данных (легкая, файловая)

- JWT - аутентификация

- bcryptjs - шифрование паролей

- CORS - безопасность межсайтовых запросов

#### Frontend (планируется)
- Vue.js
 
- Axios для HTTP-запросов

## Установка и запуск

### Клонирование репозитория
git clone [<repository-url>](https://github.com/dron-olya7/media-journal.git)

cd backend
npm install
npm start

**Или в режиме разработки**
npm run dev

Сервер будет доступен по адресу: http://localhost:3001

cd frontend
npm install
npm run dev

Доступ по адресу: http://localhost:5173/
